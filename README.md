# Hi, I'm Williams

I'm a hands-on product engineer and engineering leader based in Madrid. I've spent 20+ years building software, from fintech and data infrastructure to recruiting tools and connected photo frames.

I like small teams, useful products, and making complicated things feel simple. I enjoy building as much as helping other engineers grow.

### Things I've built

- **[memoir.](https://memoirframes.com)**: a connected e-ink photo frame, with over 80 units sold. I created the product and wrote the app and backend; my brother designed the electronics and enclosure. The source lives privately on GitLab.
- **Nova Recruiter**: co-built with one other engineer. I personally designed and implemented its multichannel campaign engine, branching workflows, and provider limits and cooldowns.
- **[timple](https://timple.food)**: a personal food-planning project, including an MCP server so AI assistants can work with it. This is a project I use myself and am still developing.

### Public code

Most of my professional work lives in private repositories. Here are a few public projects you can explore:

- **[brain-inbox](https://github.com/webnator/brain-inbox)**: a small Telegram tool for capturing text and voice notes and pulling them into Markdown. Node.js, Groq transcription, and Docker. A personal tool, with room to improve.

### How I work

My strongest production stack is **TypeScript, Node.js, React, SQL, and AWS**. I've also worked with GCP, Kubernetes, and Python for data and AI projects.

These days I use coding agents throughout development. I focus on understanding the problem, designing the solution, reviewing the result, and testing it as a user. When something goes wrong, I improve the workflow as well as the code.

Outside work, I build indie games and experiment with Unity, Godot, and Phaser. I like having something I can actually play at the end of the day.
